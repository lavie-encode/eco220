Lecture 1

Data basics

Who you're describing (sample vs population), what can go wrong (errors), and how the data are shaped (n and unit of observation).
★ Memorize
  • Statistic = sample number (X̄, s). Parameter = population number (μ, σ).
  • Sampling error = random, shrinks with n. Non-sampling error = systematic bias. Bigger n doesn't fix bias.
  • Mean of a dummy = the proportion of 1s.
  • Cross-sectional → unit = a country · Time series → a year · Panel → a country-year.
Show more: errors, data sets, Simpson's Paradox

Non-sampling error examples

Lying, misread questions, non-response bias (people who skip differ from people who answer), a sampling frame that doesn't match the target population.

TypeWhat variesUnit of observation
Cross-sectionalMany units, one perioda country
Time seriesOne unit, many periodsa year
PanelMany units × periodsa country-year

Panel in long form = one row per country-year, so n = units × periods. Tabulation = 1 variable; cross-tab = 2 together.

Simpson's Paradox

The overall rate is a weighted average of group rates. Unemployment rose in both education groups, yet overall fell (3.7% → 3.5%) because workers shifted into the low-unemployment, educated group.

Workshop 1

Percent vs percentage points

A difference = two levels + two gap measures (p.p. or units, and %).
★ Memorize
  • % change = 100 × (new − old) / old. Name the base.
  • p.p. = one % minus another. Only for things already in %.
✎ Say it like this

"About 52% of men aged 15–24 chose to compete, versus about 39% of men aged 55–64: 13 percentage points lower, or about 25% lower."

✕ Trap
  • Age groups = different people. Say "lower," never "decreases with age."
  • No "percentage points" for ounces, dollars or scores.
Show more: asymmetry, expert phrasing

% changes aren't symmetric

426.8 → 330.8 oz is −22.5%, but 330.8 → 426.8 is +29.0%.

How papers phrase it

"A 7.2 percentage point higher likelihood of stunting … an 18 percent increase relative to the sample mean of 40.2 percent." So the exposed group's rate ≈ 47.4%.

Right skew (long tail right) → mean > median. Left skew → mean < median.

✕ Trap
  • Empirical Rule on skewed data. Use percentiles or Chebyshev.
  • Read the histogram's y-axis label first (frequency, fraction or density).
Show more: histograms, centre vs spread, SD vs mean

3 histograms, same picture

Frequency (counts) · relative frequency (fractions) · density (bar area = fraction).

Centre

Mean gets pulled by tails; median doesn't.

Spread

Variance = squared units. SD = variable's units. Bigger n doesn't shrink the SD.

✎ Say it

SD ≥ mean for something that can't go below 0 → big spread, long right tail. "Credit cards: mean 1.8, SD 2.0, so holdings vary a lot."

Bell-shaped histogram: the bulk spans about 4 SDs, so SD ≈ width of bulk ÷ 4.

Lecture 3

Percentiles, Stata, box plots

Read Stata's su x, detail fast and build a box plot.
★ Memorize · box plot
  1. Box Q1 → Q3, line at median. IQR = Q3 − Q1.
  2. Fences: Q1 − 1.5·IQR, Q3 + 1.5·IQR.
  3. Whiskers stop at the last real data point inside the fences.
  4. Beyond a fence = a dot (outside value).
★ Dummy SD

Mean p → SD ≈ √(p(1−p))

★ z-score

(x − mean) / SD = SDs above (+) or below (−) the mean.

Show more: Stata output, grouped data, transformations

Reading Stata

  • Left: percentiles (25% = Q1, 50% = median, 75% = Q3).
  • Middle: 4 smallest / 4 largest. Range = max − min.
  • Right: Obs, Mean, Std. Dev., Variance, Skewness (>0 = right skew).
  • % between a and b → subtract their percentiles.

From a tabulation

Median = first value where Cum. hits 50%.

Grouped data

Mean ≈ Σ f·m; SD ≈ √Σ f(m − mean)² (f = fraction, m = midpoint).

Transformations

  • Linear (units, z-score): changes scale, not shape.
  • Log: changes shape, makes right skew more symmetric.
  • Mean of (X − Y) = mean X − mean Y; not true for median or SD.
Lecture 4

Covariance, correlation, causality

r = direction + strength of a straight-line link. Never cause.
★ Memorize
  • r is −1 to +1, no units, linear only, not about n.
  • Observational data → lurking variables → not causal. Random assignment → causal.
✕ Trap
  • Var-cov matrix diagonal = variances. Take √ first: r = cov / (√var x · √var y).
  • Don't read r like a slope ("1 unit more x → 0.15 more y").
✎ Say it

"A weak positive linear association between confidence and competitiveness (r = 0.15)."

Show more: covariance, cross-tabs, endogeneity

Covariance

Sign = direction. Units are x × y, so size is hard to judge. Standardize both → covariance = r.

Cross-tab of two dummies

  • Fill gaps: total − known cell.
  • Compare % with y = 1 in each x row. Higher when x = 1 → r positive.
  • More in (0,0) and (1,1) → r more positive / less negative.

Endogeneity bias

Name the lurking variable and direction: motivation raises attendance and learning, so the correlation overstates the causal effect.

Lecture 5

Simple regression (OLS)

Finding the line is easy. Interpreting it is where the marks are.
★ Slope checklist: all 5 every time
  1. Context
  2. Units of x and y
  3. "On average"
  4. Causal or associated
  5. Big or small?
✎ Say it

"An extra mg of the drug causes about 0.48 more hours (29 min) of sleep on average, a considerable boost." (experiment)

Observational: "is associated with," not "causes."

✕ Trap
  • Interpreting the intercept when x = 0 is outside the data.
  • R² measures fit, not cause and not slope size.
Show more: ANOVA, R², regression to the mean, units

ANOVA

SST = SSR + SSE: total = explained + leftover.

R²

SSR/SST = r². "x explains about __% of the variation in y."

  • s_e (Root MSE): typical residual size, in y units.
  • Both standardized → slope = r → regression toward the mean.
  • Swap x and y → a different line.
  • Averaged data → less scatter, higher R².
  • x hours → minutes: slope ÷ 60. y $100s → $1,000s: all ÷ 10.

★ Dummy x

Intercept = mean of the 0 group. Slope = difference in group means.

Show more: worked examples
Lin-log

happiness = −1.679 + 0.764·ln(GDP). 10% higher GDP → about 0.08 points happier on the 10-point ladder.

Dummy

happiness = 5.002 + 1.650·OECD → non-OECD avg 5.0; OECD 1.65 points happier on average (not causal). Flip the dummy: intercept 6.652, slope −1.650, same R².

Growth

ln(GDP) = a + 0.043·year → about 4.3% growth per year.

Templates and traps

Units, "on average," causal or not, and stay within the sentence count.
✕ Top traps
  • No units, or a scale score called a % (6.8/10 ≠ 68%).
  • Only one gap measure, or p.p. and % mixed up.
  • "Causes" or "becomes" with observational / cross-sectional data.
  • Wrong row, column or line: check labels and legends twice.
  • Bar chart of group means ≠ histogram.
